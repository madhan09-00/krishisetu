# 🌱 KrishiSetu (कृषि सेतु)
### Smart India Hackathon 2026 Prototype
**Problem Statement ID:** `SIH26033`  
**Theme:** Agriculture, FoodTech & Rural Development  
**Ministry:** Ministry of Consumer Affairs, Food & Public Distribution  
**Problem Title:** *Multiple intermediaries reduce farmers earnings and increase consumer prices.*

---

## 📌 Executive Summary
KrishiSetu is an AI-powered direct farm-to-fork value chain platform that eliminates commission middlemen, prevents distress selling, cuts post-harvest food waste, and guarantees fair pricing for both farmers and consumers.

### 🌟 Key Innovations (USPs)
1. **Multilingual Voice AI (Bhashini AI):** Non-tech-savvy farmers can list their harvest simply by speaking in their native dialect (Hindi, Marathi, Telugu, Tamil, English).
2. **Edge Computer Vision Crop Grading:** Instant visual scan on smartphones detecting ripeness, size uniformity, and defects—issuing a tamper-proof **Grade A/B/C Quality Certificate**.
3. **Micro-Hub Yield Pooling & Shared Freight:** Geospatial aggregation of neighboring farm produce to reduce freight costs per kg by up to 45%.
4. **Dynamic Fair-Price Corridor:** Real-time Agmarknet & e-NAM integration ensuring farmers earn **+35% to +90% more** while consumers save **20–25%**.
5. **Direct Escrow Payouts:** Milestone-based UPI/DBT release upon delivery verification, guaranteeing zero payment defaults.

## 🚀 How to Run the Prototype

### Option 1: One-Click Python Server (Recommended)
Open PowerShell / Command Prompt inside this folder and run:
```powershell
python server.py
```
This will automatically launch the prototype at `http://localhost:8000/index.html` and open it in your default web browser.

### Option 2: Direct File Open
You can also directly double-click `index.html` to open it in Google Chrome, Microsoft Edge, or Firefox.
